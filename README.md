# KISGO

카메라로 친구의 얼굴 위치를 감지하고, 프렌드볼을 던져 사진 카드를 수집하는 반응형 웹앱입니다. Pokémon GO의 포획 인터랙션을 참고했습니다.

## 실행

Node.js 22.13 이상이 필요합니다. 현재 PC에 의존성과 빌드 결과가 준비되어 있습니다.

```powershell
npm install
npm run build
npm run start
```

브라우저에서 http://localhost:3001/ 을 엽니다. 개발 수정 시에는 `npm run dev`를 사용합니다.

## 플레이

- 데모 체험: 공원 속 친구 하루를 무제한 볼로 포획합니다.
- 실제 카메라: 친구의 촬영 동의를 확인하고 카메라 권한을 허용합니다. 얼굴 한 명이 보일 때 타깃 링이 표시됩니다.
- 볼을 누른 채 위로 스와이프합니다. 길이·속도·방향에 따라 착지점이 달라지며 곡선 제스처는 커브볼입니다.
- 작은 링 안에 명중하면 Excellent, 중간 링은 Great, 그 외 명중은 Nice입니다. 포획은 확률적으로 실패할 수 있습니다.
- 키보드 사용자는 볼에 Tab으로 포커스를 두고 Enter/Space로 중앙에 던질 수 있습니다.
- 성공 후 이름을 입력하고 도감에 저장합니다. 카드를 선택하면 상세 기록을 보거나 삭제할 수 있습니다.

## 데이터와 범위

MediaPipe Face Detector를 사용한 얼굴 위치 감지입니다. 얼굴로 친구의 신원이나 이름을 자동 식별하는 기능은 포함하지 않습니다. 이름은 직접 입력합니다.

카메라 영상은 서버에 전송하지 않으며, 포획한 사진과 이름은 현재 브라우저의 IndexedDB에만 저장합니다. 서버 계정 동기화는 없고 브라우저 데이터 삭제 시 도감도 사라집니다. 브라우저 탭이 숨겨지면 카메라를 종료합니다.

휴대폰에서 실제 카메라를 사용하려면 HTTPS 배포가 필요합니다. localhost는 해당 앱 서버가 실행 중인 PC에서 이용하는 주소입니다. Sites 등록 시 계정의 push-to-deploy 기능이 비활성화되어 온라인 배포는 완료하지 못했습니다.

- 프로덕션 빌드 및 TypeScript 검사
- 타깃 경계, 링 크기에 따른 등급, 커브볼 보너스, 스와이프 거리와 속도 등 포획 판정 11개 테스트

## 3D 투척 업데이트

Three.js 구체 메시와 원근 카메라를 사용합니다. 손을 따라 움직이는 볼을 놓으면 마지막 100ms의 속도로 초기 속도를 정하고, 120Hz 고정 스텝에서 중력 9.81m/s²·속도 제곱 저항·스핀 마그누스 횡력을 적분합니다. 배경은 기존 이미지/카메라이고 볼과 궤적이 3D입니다. 회전 계수는 플레이 감각을 위해 조정한 근사 모델입니다.

커브볼은 볼을 누른 채 원을 그리고 위로 튕겨 던집니다. 양방향 회전·회전 감쇠·바닥 바운스와 포인터 취소를 지원합니다. WebGL을 사용할 수 없으면 기본 볼 표현으로 같은 3D 물리를 적용합니다.

중력, 저항, 좌우 대칭, 바운스, 투영, 키보드 조준, 회전 인식 등 물리 테스트 16개 통과. 브라우저 조작 및 실제 터치 손맛 평가는 미실시입니다.

## 모바일 전용 UI

포획 화면과 도감을 하단 탭으로 분리했습니다. 포획 화면은 기기의 동적 높이와 상하 안전 영역을 사용하고, 주요 터치 영역은 44px 이상으로 구성했습니다. BETA·슬로건·저장 안내·중복 설명은 메인 화면에서 제거했습니다. 데스크톱에서도 동일한 모바일 레이아웃으로 표시합니다.

커브볼 포획 수정: 볼 반지름을 포함한 이동 선분-타깃 구체 연속 충돌로 판정합니다. 비행 중 링을 발사 시 위치·크기로 유지하며, 명중한 커브볼은 확정 포획입니다. 일반볼의 포획 확률은 유지됩니다. 커브볼 회귀 테스트 12개 통과.
